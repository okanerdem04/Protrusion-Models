An extension of the cellular Potts model developed to study the growth of osteocyte cells and their protrusions. The program can be run by executing the main.py program. Alternatively, it is possible to run the program using the command line: `main.py <target_area> <alpha> <lambda> <signal_strength> <signal_range> <protrusionSweeps> <fileName> <alpha'> <width>`.
